# UK-BCLN-Cities-Crime-Analysis
In this report we will perform different analysis of different cities of UK (Bradford, Leicester, Nottingham and Cumbria).

This crime data analysis report analyzes and explore the crime data of four different cities (Bedfordshire, Cumbria, Leicestershire, and Nottinghamshire) of United Kingdom. The dataset is obtained from the UK police open-source website.  The aim of this analysis is to understand the different crime patterns of these cities, their distributions and to see their trends both at a high level and further localized contexts. Data will be analyzed using Apache Spark ,Spark SQL and will be visualized with the help of different plotting libraries like Matplotlib and seaborn.
The key information which our dataset contains are ‘Crime ID’, ‘Month’, ‘Reported by’, ‘Falls within’, ‘Location’, ‘LSOA name’, ‘Crime type’, and ‘Last outcome category’. Our dataset contains two years of data starting from January 2023 and ending on December 2024. Our workflow will follow data overview and initial exploration, data cleaning, trend across the years and months, crime trend across the cities and within the cities, top crime types, crime pattern, and at the end conclusion.
